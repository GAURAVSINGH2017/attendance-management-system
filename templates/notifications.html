How alerts work

When a student's attendance changes to Absent or Late, AttendEase emails the guardian and/or texts their mobile number, if that channel is configured. Re-saving the same status does not send another alert.

Enter the guardian's email and mobile number in the student's profile. Configure SMTP and Twilio credentials as private environment variables in your hosting dashboard; never put secrets in the code or GitHub. SMS providers charge per message. Recipients should agree to receive these alerts.

# Free public hosting: Render + TiDB Cloud Starter

This keeps the Flask app on a public Render URL and stores its MySQL-compatible data in TiDB Cloud Starter. Your own computer does not need to stay on. Render's free web service sleeps after 15 minutes without traffic and may take about a minute to wake for the next visitor. TiDB's free MySQL-compatible tier includes monthly quotas; if a quota is reached, new database connections stop until quota is increased or resets.

## Before publishing

1. Create a **private GitHub repository**. Upload this project's files, but do not upload `.env` or `.venv` (`.gitignore` excludes them).
2. Create a free **MySQL-compatible TiDB Cloud Starter** instance. In its SQL editor, create the database with `CREATE DATABASE attendance_db;`.
3. From the TiDB connection panel, note the host, port, username, password, and CA certificate. TiDB Starter uses TLS. Save the downloaded CA certificate as `tidb-ca.pem` in the project root and add this non-secret certificate file to GitHub.
4. In Render, create a Blueprint from the GitHub repository. It reads `render.yaml`, installs the requirements, upgrades/creates the tables, and launches Gunicorn.
5. In the Render service's Environment settings, set `DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASSWORD`, and `DB_NAME` from TiDB. Leave `DB_SSL_CA=tidb-ca.pem`. Keep `SECRET_KEY` generated by Render and `FLASK_DEBUG=false`.
6. Create the first admin in Render Environment settings with `BOOTSTRAP_ADMIN_USERNAME` and `BOOTSTRAP_ADMIN_PASSWORD` (at least 8 characters), then redeploy. After the first successful start, remove both bootstrap variables; the admin account remains saved in TiDB.
7. Open the public `onrender.com` URL. Sign in, add classes' subjects, then add students and take attendance.
8. Optional email alerts on Render: create a Resend API key and set `RESEND_API_KEY` and `RESEND_FROM` in Render. `RESEND_FROM` must use a verified sending domain (for example, `AttendEase <alerts@yourdomain.com>`). Resend's test sender can be used only for testing and is not a production sender for guardian addresses. The local SMTP settings remain available for local development.

Never put database, Resend API, SMTP, admin, or secret-key credentials in GitHub or in chat. Render's free web service can restart and its local filesystem is temporary, so keep all app records in TiDB rather than local files. This project does not send SMS alerts.
